# Personal Website

My personal website, built with [Lit](https://lit.dev/) and inspired by [Brittany Chiang's website](https://brittanychiang.com/).

**Live website:** [demo](https://aladin20c.github.io/portfolio/).

## Development

Install the dependencies:

```bash
npm install
```

Start the development server:
```bash
npm run dev
```

The project can also be built as a standalone HTML file, with all assets bundled into it:
```bash
npm run build
```
The generated index.html is placed at the project root and can be opened directly in a browser or deployed to static hosting such as GitHub Pages.
